# 阶段 00：基础设施与工程脚手架

> 前置阶段，所有后续阶段的依赖。本阶段完成后，后续模块只需在其上增量开发。

## 1. 目标
搭建前后端工程骨架、中间件环境、统一框架（返回/异常/鉴权/文件/向量库连接），使后续阶段可「开箱即用」地进行业务开发。

## 2. 前置依赖
无。

## 3. 验收标准
- [ ] 后端 `mvn spring-boot:run` 启动成功，`GET /api/v1/health` 返回 `{"code":0,"message":"success","data":{"status":"UP"}}`。
- [ ] `docker compose up -d` 拉起 PostgreSQL、Redis、MinIO、Milvus（或 Chroma），后端能连通并打印连接成功日志。
- [ ] Swagger/OpenAPI 页面可访问（`/swagger-ui.html`）。
- [ ] 统一返回体、统一异常处理、全局 CORS、日志配置生效。
- [ ] 前端 `pnpm dev`（或 npm）启动，可访问空壳首页并成功调用 `/api/v1/health`。

## 4. 范围

### In Scope
- 后端 Maven 工程（Spring Boot 3.x + Java 17）与 `pom.xml` 关键依赖。
- Docker Compose 编排 PG / Redis / MinIO / Milvus。
- 统一返回 `ApiResponse<T>`、全局异常 `@RestControllerAdvice`、错误码枚举。
- 鉴权：MVP 单用户模式，预留 JWT 过滤器（默认放行）。
- 通用配置：MinIO 客户端、RedisTemplate、Embedding HTTP 客户端占位、异步线程池、Swagger。
- 前端 Vue3 + Vite + Element Plus + Pinia + Axios 骨架与 `/health` 联调。

### Out of Scope（防膨胀）
- 不实现任何业务模块（竞赛/知识库/智能体等）。
- 不实现复杂 RBAC 权限、多租户、微服务拆分。
- 不引入本地大模型推理。

## 9. 关键实现要点与约束
- `application.yml` 中所有中间件地址、模型接口地址、Embedding 地址均走环境变量，提供默认值。
- 统一错误码约定：`0` 成功、`400xx` 参数错误、`500xx` 服务错误、`404xx` 资源不存在。
- MinIO、Milvus 启动时做连接自检并打日志，失败不阻塞启动（可降级）。
- 异步线程池参数预留，供 PPT/视频长任务使用。
