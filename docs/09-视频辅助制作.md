# 阶段 09：视频辅助制作（脚本 + 配音 + 素材合成）

> **严守边界**：仅做「LLM 脚本 → TTS 配音 → FFmpeg 素材合成」三段式，生成可播放 MP4。**不碰视频生成大模型。**

## 1. 目标
异步生成项目介绍视频：用户上传项目截图或演示片段，LLM 生成解说词/分镜脚本 → TTS 合成配音（mp3）→ FFmpeg 模板化合成（截图/片段 + 音频 → mp4，可含字幕），产物存 MinIO 可播放。

## 2. 前置依赖
阶段 00、06、07（脚本内容依赖方案/选题）。

## 3. 验收标准
- [ ] 提交任务后异步生成脚本 + 配音 + 合成视频。
- [ ] 产出可播放 MP4（含音频；有素材时含画面）。
- [ ] 支持查询进度（分阶段状态）与下载/播放。
- [ ] 不调用任何视频生成模型。

## 4. 范围

### In Scope
- LLM 脚本生成（含分镜/旁白文本）。
- TTS（Edge-TTS 或云 TTS）生成 mp3。
- FFmpeg 合成（ProcessBuilder / ffmpeg-cli-wrapper）。
- 异步任务与进度上报。

### Out of Scope（硬边界）
- **禁止**视频生成大模型（如 Sora/可灵）。
- 不做视频剪辑器 UI。
- 素材库（项目截图/演示片段）由用户上传或内置占位图，不自研生成。

## 5. 数据模型
复用 `generation_task`（task_type=VIDEO）。新增脚本表：
```sql
CREATE TABLE video_script (
    id          BIGSERIAL PRIMARY KEY,
    task_id     BIGINT NOT NULL REFERENCES generation_task(id),
    scenes      JSONB,                              -- 分镜 [{text, durationSec, imageUrl}]
    full_text   TEXT,                               -- 完整旁白
    created_at  TIMESTAMPTZ DEFAULT now()
);
```

## 6. API 契约

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/video/generate` | 提交视频生成任务 |
| GET | `/api/v1/tasks/{taskId}` | 查询进度（含子阶段） |
| GET | `/api/v1/video/{taskId}/download` | 下载/播放 MP4 |

请求：
```json
{ "projectId": 1, "images": ["minio://material/a.png","minio://material/b.png"] }
```

任务进度（data 内）：
```json
{ "taskId": 2, "status": "RUNNING", "stage": "TTS",
  "progress": 60, "fileUrl": null }
```
`stage` 取值：`SCRIPT / TTS / COMPOSING / DONE`。

## 7. 核心流程（异步，分段上报）
1. 创建 generation_task（VIDEO, PENDING）。
2. **脚本**：LLM 依据 project/plan 生成分镜脚本（每段旁白 + 时长 + 配图映射），存 video_script，进度 20%。
3. **配音**：逐段调用 TTS 生成 mp3（Edge-TTS/云 TTS），进度 60%。
4. **合成**：FFmpeg 将图片/音频按分镜拼接，可选加字幕，输出 mp4，进度 90%。
5. 上传 MinIO → 任务 SUCCESS + fileUrl，进度 100%。
6. 任一步失败 → FAILED + errorMsg。

## 9. 关键实现要点与约束
- FFmpeg 通过 `ProcessBuilder` 调用外部进程，命令参数白名单化，禁止注入。
- TTS 与 FFmpeg 需处理超时、失败重试与临时文件清理。
- 进度写入 `generation_task`（可扩展 `progress`/`stage` 字段或 Redis）。
- **代码注释显式声明：不调用视频生成模型。**
