# 阶段 03：竞赛规则解读（RAG 问答）

> 基于阶段 02 知识库实现「规则问答」，回答报名/评分/材料等要求，**强制标注出处**（页码/来源），并自动过滤过期规则。

## 1. 目标
面向某一竞赛（或全库），用 RAG 回答用户关于报名条件、评分标准、材料要求等规则问题，回答必须附出处与发布日期，禁用过期规则。

## 2. 前置依赖
阶段 00、02。

## 3. 验收标准
- [ ] 输入规则问题，返回答案 + 引用列表（来源、页码、发布日期）。
- [ ] 自动过滤过期规则（按 `sourceDate` / 竞赛状态）。
- [ ] 无命中时给出「未检索到相关规则」的明确降级，不编造。
- [ ] 支持限定竞赛范围提问（competitionId）。

## 4. 范围

### In Scope
- RAG 问答接口（检索 + LLM 生成，附引用）。
- 过期规则过滤。
- 无命中降级。

### Out of Scope
- 不做流式（SSE 流式在阶段 06 智能体统一实现）。
- 不做多轮对话记忆（MVP 单轮）。
- 不实现自定义重排模型。

## 5. 数据模型
复用阶段 02 的 `document` / `document_chunk` 与向量库，无需新增表；可新增 `qa_log`（可选）：
```sql
CREATE TABLE qa_log (
    id          BIGSERIAL PRIMARY KEY,
    question    TEXT NOT NULL,
    answer      TEXT,
    refs        JSONB,                       -- 引用列表 [{source,pageNumber,sourceDate}]
    created_at  TIMESTAMPTZ DEFAULT now()
);
```

## 6. API 契约

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/rules/qa` | 规则问答 |

请求/响应：
```json
// 请求
{ "question": "本科组报名需要什么材料？", "competitionId": 1, "topK": 5 }

// 响应 data
{
  "answer": "根据《报名须知》第2页：本科组需提交报名表、学生证复印件……",
  "references": [
    { "source": "https://example.com/notice.pdf", "pageNumber": 2,
      "sourceDate": "2025-12-01", "score": 0.87 }
  ],
  "fallback": false
}
```

## 7. 核心流程
1. 校验 `question` 非空。
2. 检索：`VectorStoreService.search`（限定 competitionId、过滤过期规则、topK）。
3. 组装提示词：注入检索片段 + 出处，要求 LLM「只依据片段作答，逐条标注出处；片段不足则说明未检索到」。
4. 调用 LLM 生成答案，返回 answer + references。
5. 若 topK 命中数 < 阈值或相关度 < 阈值 → `fallback=true`，answer 提示未检索到，禁止编造。
6. 记录 qa_log（可选）。

## 9. 关键实现要点与约束
- **强制证据链**：回答必须附 `references`（source/pageNumber/sourceDate）。
- 过期过滤：检索 metadata 的 `sourceDate`，或关联竞赛 `status != EXPIRED`。
- 提示词必须约束「禁止编造、禁止预测获奖」。
- LLM 调用走 Spring AI OpenAI 兼容接口，模型/温度配置化。

## 10. AI 实现提示词

```text
请基于阶段02知识库（已有 VectorStoreService.search 与 DocumentChunk 实体），实现「竞赛规则解读」
模块。

【必须实现】
1. RuleQaService：
   - 输入 QaRequest(question, competitionId, topK)；
   - 调用 VectorStoreService.search，若 competitionId 非空则过滤 metadata.competition_id；
   - 过滤过期规则：sourceDate 早于竞赛截止或 status=EXPIRED 的片段剔除；
   - 组装 Prompt（中文）：包含「你是竞赛规则助手，只依据给定片段作答，逐条标注出处
     [来源 页码]，禁止编造，禁止预测获奖；片段不足则回答未检索到」+ 检索片段；
   - 调用 Spring AI ChatClient（OpenAI 兼容）生成答案；
   - 返回 QaResponse(answer, references[{source,pageNumber,sourceDate,score}], fallback)。
2. RuleQaController：POST /api/v1/rules/qa，返回 ApiResponse。
3. 可选：qa_log 表与保存逻辑。
4. 前端 RuleQa.vue：输入框 + 竞赛选择 + 提问按钮，展示答案与引用列表（Element Plus）。

【输出要求】
- 代码带中文专业注释，符合企业级规范；
- 强制证据链与禁止编造/禁止预测获奖的约束必须体现在代码注释与 Prompt 中；
- 不实现流式输出与多轮记忆。
```
