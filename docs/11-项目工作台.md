# 阶段 11：项目工作台

> 聚合展示：项目版本、材料、任务进度、AI 生成日志，是用户操作与查看的统一入口。

## 1. 目标
围绕 project 聚合展示选题分析报告、方案、PPT/视频任务、申报检查结果与 AI 生成日志，形成完整工作台页面。

## 2. 前置依赖
阶段 00、06、07、08、09、10（依赖全部业务模块数据）。

## 3. 验收标准
- [ ] 项目详情页聚合展示：分析报告、方案、PPT/视频任务状态、申报检查、生成日志。
- [ ] 可查看/下载已生成的 PPT 与视频。
- [ ] 生成日志（agent_trace / generation_task）可视化时间线。

## 4. 范围

### In Scope
- 项目聚合查询接口（一次返回各模块摘要）。
- 工作台前端页面（Tab 组织各模块）。
- 任务/日志时间线。

### Out of Scope
- 不做全新业务逻辑（仅聚合既有模块数据）。
- 不做多用户协作/权限（MVP）。

## 5. 数据模型
复用既有表，无新表（可加视图或聚合 DTO）。

## 6. API 契约

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/workbench/projects/{projectId}` | 聚合工作台数据 |
| GET | `/api/v1/workbench/projects` | 项目列表 |

聚合响应 data：
```json
{
  "project": { "id": 1, "title": "基于计算机视觉的中药材识别系统", "status": "ANALYZED" },
  "latestReport": { "reportId": 1, "summary": "规则匹配…", "createdAt": "…" },
  "plan": { "id": 1, "title": "…" },
  "tasks": [ { "taskId": 1, "taskType": "PPT", "status": "SUCCESS" },
             { "taskId": 2, "taskType": "VIDEO", "status": "RUNNING", "stage": "TTS" } ],
  "applyCheck": { "id": 1 },
  "traces": [ { "step": 1, "toolName": "searchRules", "summary": "命中 3 条规则" } ]
}
```

## 7. 核心流程
1. 按 projectId 并行查询各模块最新数据（报告、方案、任务、检查、日志）。
2. 组装聚合 DTO 返回。
3. 前端以 Tab / 时间线呈现。

## 8. 文件结构
```
backend/.../workbench/
├── dto/ WorkbenchVO.java
├── service/ WorkbenchService.java
└── controller/ WorkbenchController.java
frontend/src/
├── api/workbench.ts
└── views/workbench/ Workbench.vue, ProjectList.vue
```

## 9. 关键实现要点与约束
- 聚合接口只做读汇总，不做写逻辑。
- 各模块查询失败应降级（返回空字段），不拖垮整页。
- 时间线按时间倒序合并 trace 与 task 事件。

## 10. AI 实现提示词

```text
请实现「项目工作台」模块（Spring Boot 3 + Java 17，根包名 com.graduation.competition，
已有 project/analysis_report/project_plan/generation_task/agent_trace/application_check
等实体与 Repository 可复用）。

【必须实现】
1. WorkbenchVO（聚合 DTO）：project、latestReport、plan、tasks[]、applyCheck、traces[]。
2. WorkbenchService：
   - 按 projectId 查询各模块最新数据并组装；任一模块失败降级返回空字段；
   - 提供项目列表方法。
3. WorkbenchController：
   - GET /api/v1/workbench/projects/{projectId}；
   - GET /api/v1/workbench/projects。
4. 前端：
   - ProjectList.vue：项目列表（Element Plus 表格，点击进入详情）；
   - Workbench.vue：Tab 展示「分析报告(Markdown 渲染)/方案/PPT/视频(含播放与下载)/
     申报检查/生成日志(时间线)」。

【输出要求】
- 代码带中文专业注释；聚合只读、模块失败降级；
- 不新增业务逻辑，仅聚合既有模块数据。
```
