# 阶段 04：智能竞赛检索

> 基于用户画像（年级、方向）与竞赛/资料向量，做语义化竞赛推荐，让「该参加什么比赛」有据可依。

## 1. 目标
输入用户画像（年级、专业方向、关键词），返回按相关度排序的竞赛推荐列表，并给出推荐理由（命中点 + 出处）。

## 2. 前置依赖
阶段 00、01、02。

## 3. 验收标准
- [ ] 输入「大二 / 计算机视觉 / 机器学习」，返回相关竞赛排序列表。
- [ ] 每项推荐附推荐理由与匹配关键词/来源。
- [ ] 自动排除已过期竞赛。
- [ ] 支持分页/数量控制。

## 4. 范围

### In Scope
- 竞赛结构化字段过滤（级别/类别/时间）。
- 画像与竞赛简介/资料的语义匹配（向量检索）。
- 推荐理由生成（基于命中片段）。

### Out of Scope
- 不做协同过滤/复杂推荐系统。
- 不做爬虫实时数据。
- 不生成完整分析报告（那是阶段 06）。

## 5. 数据模型
复用 `competition`、`document` 与向量库。新增画像请求 DTO 即可（无需新表）。

## 6. API 契约

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/search/recommend` | 基于画像推荐竞赛 |

请求/响应：
```json
// 请求
{ "grade": "大二", "direction": "计算机视觉", "keywords": ["机器学习","图像识别"], "limit": 10 }

// 响应 data
{
  "recommendations": [
    { "competitionId": 1, "name": "中国大学生计算机设计大赛",
      "level": "国家级", "reason": "该赛事设软件应用与开发组别，与你的「计算机视觉」方向匹配",
      "matchedKeywords": ["计算机视觉","图像识别"],
      "source": "https://example.com/notice", "sourceDate": "2025-12-01", "score": 0.86 }
  ]
}
```

## 7. 核心流程
1. 组装查询文本：`grade + direction + keywords` 拼接。
2. 结构过滤：排除 `status=EXPIRED` / 报名已截止的竞赛。
3. 语义检索：查询文本向量化 → 在知识库检索与竞赛简介/资料匹配的片段，聚合到对应 competitionId。
4. 排序：按得分聚合排序，取 topN。
5. 生成推荐理由：用 LLM 基于命中片段简述匹配点（可选，可退化为关键词命中说明）。
6. 返回列表（含出处）。

## 9. 关键实现要点与约束
- 画像字段可缺省；缺省时仅按 direction+keywords 检索。
- 结果必须携带 `source`/`sourceDate`（证据链约定）。
- 与阶段 06 智能体「Step1 检索赛事」复用同一检索能力，抽出公共方法。

## 10. AI 实现提示词

```text
请基于已实现的知识库检索能力与竞赛信息管理，实现「智能竞赛检索」模块。

【必须实现】
1. RecommendService：
   - 输入 RecommendRequest(grade, direction, keywords[], limit)；
   - 过滤：排除 status=EXPIRED 或 registerEnd < today 的竞赛（查 competition 表）；
   - 语义检索：拼接 grade+direction+keywords 作为 query，调用 VectorStoreService.search，
     按 metadata.competition_id 聚合 score，取 topN；
   - 推荐理由：用 Spring AI ChatClient 基于命中片段生成一句匹配理由（禁止编造、禁止预测获奖）；
   - 返回 RecommendResult 列表（competitionId/name/level/reason/matchedKeywords/source/
     sourceDate/score）。
2. RecommendController：POST /api/v1/search/recommend，返回 ApiResponse。
3. 前端 Recommend.vue：画像表单（年级/方向/关键词）+ 推荐卡片列表（Element Plus）。

【输出要求】
- 代码带中文专业注释；结果必须带 source/sourceDate；
- 复用阶段02的 VectorStoreService，勿重复造轮子；
- 不实现协同过滤与爬虫。
```
