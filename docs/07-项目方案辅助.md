# 阶段 07：项目方案辅助

> 基于选题分析结果，用 LLM 生成项目方案（需求分析、模块清单、技术路线），为 PPT/视频制作提供内容源。

## 1. 目标
输入选题（及可选的分析报告），LLM 生成结构化的项目方案：需求分析、功能模块清单、技术路线、开发计划，供后续 PPT/视频填充。

## 2. 前置依赖
阶段 00、06。

## 3. 验收标准
- [ ] 输入选题，生成结构化方案（需求/模块/技术路线/计划）。
- [ ] 方案可关联 project，持久化可复用。
- [ ] 内容可被阶段 08/09 直接消费（结构化字段，非纯自由文本）。

## 4. 范围

### In Scope
- 方案生成（LLM，结构化输出）。
- 方案 CRUD 与关联 project。
- 结构化字段：title/背景/需求分析/模块清单[]/技术路线/创新点/计划。

### Out of Scope
- 不做原型设计图。
- 不自动排版 PPT（阶段 08）。

## 5. 数据模型

```sql
CREATE TABLE project_plan (
    id           BIGSERIAL PRIMARY KEY,
    project_id   BIGINT NOT NULL REFERENCES project(id),
    title        VARCHAR(255),
    background   TEXT,                          -- 背景
    requirements TEXT,                          -- 需求分析
    modules      JSONB,                         -- 模块清单 [{name,description}]
    tech_route   TEXT,                          -- 技术路线
    innovation   TEXT,                          -- 创新点
    schedule     TEXT,                          -- 开发计划
    created_at   TIMESTAMPTZ DEFAULT now()
);
```

## 6. API 契约

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/plans/generate` | 生成方案（LLM） |
| GET | `/api/v1/plans/{projectId}` | 获取方案 |
| PUT | `/api/v1/plans/{id}` | 编辑方案 |

请求/响应：
```json
// 请求
{ "projectId": 1 }
// 响应 data
{ "title": "基于计算机视觉的中药材识别系统方案",
  "background": "……", "requirements": "……",
  "modules": [ {"name": "图像采集模块", "description": "……"} ],
  "techRoute": "Vue3 + Spring Boot + YOLOv8 + Milvus",
  "innovation": "……", "schedule": "……" }
```

## 7. 核心流程
1. 读取 project + 最新 analysis_report（若存在，作为上下文）。
2. Prompt 要求 LLM 输出 JSON 结构化方案（严格按 schema）。
3. 解析 JSON（容错：抽取代码块、二次校验），保存 project_plan。
4. 返回结构化结果。

## 9. 关键实现要点与约束
- LLM 输出用 JSON 模式（或要求返回严格 JSON），并做 schema 校验/容错解析。
- 模块清单用 `modules` JSONB，供 PPT/视频分段渲染。
- 禁止编造与获奖预测。

## 10. AI 实现提示词

```text
请实现「项目方案辅助」模块（Spring Boot 3 + Java 17 + Spring AI，根包名 com.graduation.competition，
已有 project/analysis_report 实体可复用）。

【必须实现】
1. 实体 ProjectPlan（projectId/title/background/requirements/modules JSONB/techRoute/innovation/
   schedule/createdAt）+ 对应 JpaRepository。
2. PlanService：
   - generate：读取 project 与最新 analysis_report 作为上下文，Prompt 要求输出严格 JSON（含
     title/background/requirements/modules[{name,description}]/techRoute/innovation/schedule），
     禁止编造、禁止预测获奖；解析 JSON（容错抽取代码块）后保存；
   - getByProjectId、update。
3. PlanController：POST /api/v1/plans/generate、GET /api/v1/plans/{projectId}、PUT /api/v1/plans/{id}。
4. 前端 PlanView.vue：展示/编辑结构化方案（模块清单用表格或卡片）。

【输出要求】
- 代码带中文专业注释；LLM 输出按严格 JSON 并做容错解析；
- 模块清单字段可供后续 PPT/视频分段消费。
```
